# Contributing to OmniGenis

OmniGenis is publicly visible but is not automatically open for unrestricted reuse or contribution. The root LICENSE controls repository-native material.

Any proposed contribution must preserve the repository's architecture, scientific evidence rules, security controls, third-party licensing obligations, and human merge gate described in AGENTS.md.

## Contribution provenance

A contribution that changes implementation or governed technical documentation must be traceable through Git and pull-request history. Governed change sets also use the Stage 8 contribution-provenance ledger and deterministic file manifest.

The provenance declaration records technical origin and whether human/tool assistance was involved. It is not a legal ownership adjudication and must not be used to infer assignment, employment status, or exclusive ownership.

Third-party code, data, text, specifications, or other protected material must not be copied into the repository unless the applicable rights, license, attribution, and purpose restrictions have been reviewed and recorded through the existing compliance controls.

## Merge authority

No contribution is merged automatically. Required automated checks and external reviews are evidence inputs; final merge authority remains human.
