# Third-Party License Evidence

This directory stores exact upstream license texts, notices, and related evidence for third-party artifacts used by OmniGenis.

Recommended layout:

`licenses/<component>/<version-or-digest>/LICENSE`

Do not edit upstream license text when preserving a license artifact. Record source URL, version or digest, retrieval date, and integrity hash in the corresponding compliance registry.

The presence of a license file here does not itself approve a dependency. Approval status is determined by the compliance registry and the repository licensing policy.
